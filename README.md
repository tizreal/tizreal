## Projects

### TrackLo
Multi-tenant request and workflow platform. Each workspace's data is isolated, a six-stage workflow is enforced on the server, and concurrent work claims are resolved safely with conditional SQL updates.

**Stack:** Java 21, Spring Boot, Spring Security, PostgreSQL, React, TypeScript
**Links:** [Live demo](https://tracklo-ui.vercel.app/) (source is private)

### UserManager
Account management and a small social feed with role-based administration. Authorization is enforced on the server, password-reset links are single-use and stored hashed, and changing a password signs out every session. 141 tests run against real PostgreSQL in CI.

**Stack:** Spring Boot, Spring Security, PostgreSQL, Flyway, Testcontainers, React
**Links:** [Backend](https://github.com/tizreal/UserManager-Backend) · [Frontend](https://github.com/tizreal/usermanager-frontend) · [Live demo](https://usermanager-frontend.vercel.app/)

### Library Management System
Books and members CRUD, with the same REST API implemented twice: once in Spring Boot and once in Express.

**Stack:** Spring Boot, Node.js, Express, PostgreSQL, React
**Links:** [Spring Boot API](https://github.com/tizreal/LibraryAppBackend) · [Express API](https://github.com/tizreal/LibraryAppExpressBackend) · [Frontend](https://github.com/tizreal/LibraryApp) · [Live demo](https://library-app-hazel-psi.vercel.app/) (shared public sandbox)

### Portfolio
Personal site with accessibility features, privacy-friendly analytics, and CI.

**Stack:** Next.js, React, Tailwind CSS
**Links:** [Source](https://github.com/tizreal/my-portfolio) · [Website](https://my-portfolio-nine-omega-88.vercel.app)
